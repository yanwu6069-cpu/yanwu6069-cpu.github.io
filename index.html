用于整理个人财务、饮食和资产记录的 Windows 本地工具。

应用说明 隐私政策 使用说明与条款

应用用途

本应用面向本人使用。财务记录、来源证据、人工修正、设置和运行状态保存在本人电脑的本地 SQLite 数据库及本地文件中，并通过本机管理界面查看。

  • 整理经正常授权取得的支付平台记录，区分来源观察、待核对记录和已确认账本。
  • 汇总收支、还款和投资净投入；明确标注数据缺失、覆盖未知及尚未完成的对账。
  • 分别记录食品购买与实际食用，仅在有食品、份量和营养依据时计算已记录部分。
  • 整理本人录入的持仓、现金和定投执行记录，保存公开市场指标；不自动买卖或支付。

平台登录、扫码及安全验证由本人完成。应用不获取支付密码或验证码，不绕过安全验证。尚未连接的数据源不会被描述为已取得真实数据。

为什么需要 Gmail 授权

独立邮件程序使用本人授权的 Google 账号，通过 Gmail API 向本人配置的邮箱发送中文摘要月报，以及已启用的采集异常或需要本人验证的提示。

当前自用配置仅申请 https://www.googleapis.com/auth/gmail.send，用于发送邮件；不申请读取收件箱、删除邮件或管理邮箱的权限，也不读取无关邮件。若未来功能需要额外权限，应先说明用途并由本人另行授权。

摘要可能包含已确认账本金额合计、分类与来源覆盖、已记录营养汇总、已录入资产概况和公开市场观察。邮件不附带原始账本，不包含单笔交易、账号、交易对方、商户或菜名。具体数据处理方式见隐私政策。

运行与数据边界

OAuth 配置和访问令牌使用当前 Windows 用户的 DPAPI 加密保存在本机。邮件程序不依赖聊天工具、模型额度或第三方邮件中转服务；向 Google 发送邮件时，Google 会处理发送所需的地址、授权凭据和邮件内容。

授权可能因撤销、到期或账号安全策略而失效；应用不能保证永久授权或始终准时发送。需要重新登录或授权时，由本人处理。缺少数据时保留未知，不将采集成功等同于完整对账，不将购买等同于食用，不将估值指标等同于交易指令。

这个静态说明站点只介绍应用与隐私处理，不提供账本登录、原始财务数据下载、支付或交易功能。
